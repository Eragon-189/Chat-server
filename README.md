# Chat-server 
    A chat room to chat with friends over the web.
## How I built it
The server side is made with Python, and the client side with HTML, CSS, and JS. I used web sockets to communicate between the client and server. The server uses asyncio to support more users. 

## Requirements 
 - Server to host on.
## Getting Started
1. Ensure ports 80 and 443 on your firewall are allowed.

2. Copy and paste this into your terminal:

git clone https://github.com/Eragon-189/Chat-server.git
cd Chat-server
bash install.sh


3. Change the script.js URI to your domain.

4. Go to https://github.com/Eragon-189/Chat-server and download the zip.

5. Open the index.html in the client folder on your device

6. Chat with friends
