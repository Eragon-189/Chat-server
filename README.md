# Chat-server 
    A chat room to chat with friends over the web.
## How I built it
The server side is made with python and the clint side with HTML, CSS and JS. I used websocets to comunicate between the cilent and server. The server uses acyncio to support more users. 
## Features
 - Chat with firends 
## Requirements 
 - Server to host on.
## Getting Started
1 Ensure port 80 and 443 on your firewall are allowed
2 Copy and paste this into your terminal:

git clone https://github.com/Eragon-189/Chat-server.git
cd Chat-server
bash install.sh


3 change the script.js uri to the ip of your server
4 Chat with friends
